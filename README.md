# 三麻オレンジ杯 — ホームページ（プレビュー）

じゃんたま（雀魂）三人麻雀のチーム戦「三麻オレンジ杯」の静的サイトです。  
配色は **オレンジを基調にした可愛いポップな雰囲気**（アクセント `#FF7A1A`）。

このリポジトリはプレビュー公開用です。本番用リポジトリはまだ作成していません。

プレビューURL: https://mizuno-kazunari.github.io/sanma-orange-cup-2027-preview/

## ロゴの差し替え

いま使っているのは仮ロゴです。正式ロゴは次の場所に上書きしてください（GitHub上で直接アップロードして大丈夫です）。

- 仮ロゴのファイル: `images/logo.svg`
- 表示箇所: `index.html` の `img.hero__logo`（`src="images/logo.svg"`）

PNGで差し替える場合は、`images/logo.png` を追加し、`index.html` の `src` を `images/logo.png` に変更してください。ファビコン（`<link rel="icon">`）も同じパスに合わせると見た目が揃います。

## エントリーフォームのURL

Googleフォームができたら、**次の1か所だけ**書き換えてください。

- ファイル: `js/config.js`
- 項目: `ENTRY_FORM_URL`

いまは `"#"`（準備中）です。フォームのURLに変えると、ページ上のエントリーボタンが自動でそのリンクに切り替わります。

## ローカルで開く

```bash
cd sanma-orange-cup-2027
python3 -m http.server 8080
```

ブラウザで http://localhost:8080/ を開く。

## 構成

```
sanma-orange-cup-2027/
├── index.html
├── README.md
├── css/styles.css
├── js/config.js      # エントリーフォームURL（ここだけ差し替え）
├── js/main.js
├── data/results.json # リザルト（開幕後に更新）
└── images/logo.svg   # 仮ロゴ（正式ロゴに差し替え）
```

- エントリー受付期間、大会ID、予選と決勝の日程割り振り
- 切り上げ満貫・飛び・配信遅延など、ルールの細目
